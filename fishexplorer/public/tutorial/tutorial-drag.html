Drag and Drop 3D Regions

Biologists often want to compare several anatomical regions. For this it is important that the user is able to move the region to a user-specific location and then move it back to the original location (once comparison is done). This tutorial provides a step-by-step guide for the dragging and collapsing of anatomical regions in the 3D viewer.As use case we choose the regions Diencephalon, Diencephalon - Anterior preoptic dopaminergic cluster and Diencephalon - Caudal Hypothalamus.

To perform such a comparison, follow the steps below:
  • First, we load anatomical regions in the 3D viewer as shown below. Please go through the Visualize 3D Regions tutorial if you don’t know how to load anatomical regions in the 3D viewer.

  • In order to enable dragging functionality, press the button (encircled red in the image above). The button will turn to green. Once dragging is enabled, you can select the object for dragging, e.g. the Diencephalon, in the 3D-Viewer by clicking the object. Then a rectangular box will appear around the selected region as shown below. You can then drag the object to any location of your choice in the viewer. In the image below, we dragged the Diencephalon to the left of the slice.

  • Similarly, all other anatomical regions e.g Diencephalon - Anterior preoptic dopaminergic cluster and Diencephalon - Caudal Hypothalamus are dragged to right of slice as shown below.

  • Now we want to move them back to their original locations. This is achieved by clicking the “collapse button”, encircled red in the image below.
